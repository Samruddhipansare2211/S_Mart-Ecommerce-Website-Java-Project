# 🛒 Smart E-Commerce Website – Internship Project

## 📌 Project Description
This is a smart e-commerce web application developed during my internship. It allows users to browse products, manage a shopping cart, and perform a basic checkout. Admins can manage product listings through a backend panel. The project uses Java, Spring Boot, and MySQL with a Thymeleaf-based front end.

## 🔧 Technologies Used
- Java 17  
- Spring Boot 3.2.4  
- Spring MVC  
- Spring Data JPA  
- Thymeleaf  
- MySQL  
- Maven  

## 🎯 Features
- 🔐 User Authentication & Authorization  
- 🛍️ Product Listing  
- 🛒 Add to Cart & Remove from Cart  
- 💳 Basic Checkout  
- 🧑‍💼 Admin Product Management  
- 🖼️ Dynamic Pages using Thymeleaf  
- 🔄 RESTful Routing
